# Macindows Reference Map

- Primary theme page: https://vsthemes.org/en/themes/windows10/26923-macindows.html

- The VSThemes page could not be fetched during this pass. This map distinguishes visible evidence from interpretation.

## What is visible in the original preview

1. **Pastel geometric wallpaper**: large, soft-edged diagonal/wave-like regions in mint, pale cream and blush. The wallpaper is a major identity element, not a tiny decorative card background.
2. **A deliberate outer frame**: the desktop is composed inside a dark, rounded perimeter. The border frames the whole scene and makes it feel like a designed environment.
3. **Window hierarchy**: windows have a narrow top chrome, compact controls and a clearly separated content area. Multiple windows overlap at different sizes.
4. **Warm light surfaces**: content panels are cream rather than pure white. Borders and text use dark charcoal instead of harsh pure black everywhere.
5. **A coordinated dark variant**: the second preview changes the surface and wallpaper treatment while retaining the same visual grammar.
6. **A dock/taskbar**: a compact strip of app icons anchors the desktop near the bottom. It is a navigation motif, not an arbitrary row of buttons.
7. **Consistent icon language**: folders, app shortcuts and status widgets use a matching icon family and consistent visual weight.
8. **Small utility labels**: desktop labels and window chrome are compact, while the primary windows remain the visual focus.

## What must not be copied literally

- Windows shell controls, system tray and desktop icons are metaphors for a web application, not requirements to recreate an operating system.
- Do not copy proprietary theme assets or icons without checking their license. Recreate the design language with original CSS/SVG and the project's Lucide icons.
- Do not use a wallpaper behind every dense table. The desktop canvas carries the wallpaper; data surfaces need a calmer, opaque reading area.

## Evidence and confidence

- High confidence: pastel wallpaper, rounded outer frame, cream windows, charcoal framing, compact window bars, light/dark variants, icon dock. These are visible in the original preview.
- Medium confidence: exact spacing, typeface, shadow blur, border widths and wallpaper colors. The image is a screenshot, not the original source tokens.
- Not verified: the exact files bundled in the VSThemes download, installation instructions, font names and icon licensing. The source page fetch failed.
